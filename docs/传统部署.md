# Fly 传统部署（非 Docker）

适用环境：一台装有 PostgreSQL、JDK 21、Node.js 的 Linux 服务器，用 Nginx 统一入口。
全新 Rocky Linux 9.8 / 10.x（Minimal）从零装齐上述软件见「零、系统准备」，已装齐可跳过。

## 前置条件

| 组件 | 版本 | 用途 |
|:-----|:-----|:-----|
| PostgreSQL | 16+（含 contrib） | 数据库 |
| JDK | 21+ | 后端运行 |
| Maven | 3.9+ | 后端构建 |
| Node.js | 22+ / pnpm | 前端与管理后台构建 |
| Nginx | 1.20+ | 反向代理 |

## 零、系统准备（Rocky Linux 9.8 / 10.x Minimal，仅全新服务器）

```bash
# 基础工具（Minimal 不全）
sudo dnf install -y tar gzip curl openssl

# PostgreSQL 16（contrib 必装：init_db.sql 依赖 pgcrypto 扩展）
sudo dnf install -y https://download.postgresql.org/pub/repos/yum/reporpms/EL-$(rpm -E %{rhel})-x86_64/pgdg-redhat-repo-latest.noarch.rpm
sudo dnf module -y disable postgresql || true   # 仅 Rocky 9 需要（屏蔽自带 PG 模块）；Rocky 10 无此模块，忽略报错
sudo dnf install -y postgresql16-server postgresql16-contrib
sudo postgresql-16-setup --initdb
sudo systemctl enable --now postgresql-16

# 数据库密码（后端走 TCP + 密码连接；PGDG 默认 postgres 无密码，不设后端起不来）
# 设置后须同步到 fly-backend/.env 的 SPRING_DATASOURCE_PASSWORD
sudo -u postgres psql -c "ALTER USER postgres PASSWORD '你的数据库密码';"

# JDK 21
sudo dnf install -y java-21-openjdk java-21-openjdk-devel

# Maven 3.9（Rocky 10 AppStream 满足 3.9+；Rocky 9 自带版本偏低需手动装）
sudo dnf install -y maven && mvn -version      # 确认 ≥3.9，否则从 maven.apache.org 装二进制包

# Node.js 22 + pnpm（pnpm 经 corepack 启用，随 Node 22 提供）
curl -fsSL https://rpm.nodesource.com/setup_22.x | sudo bash -
sudo dnf install -y nodejs
sudo corepack enable && pnpm --version

# Nginx
sudo dnf install -y nginx

# 防火墙放行 HTTP/HTTPS（云主机另需在安全组放行 22/80/443）
sudo firewall-cmd --permanent --add-service=http --add-service=https
sudo firewall-cmd --reload

# SELinux：保持 enforcing 即可，但必须放行 nginx 反代本机端口，否则全站 502
sudo setsebool -P httpd_can_network_connect 1
```

> 内存 2 GB 的机器先加 swap（否则前端 `pnpm build` OOM），命令见 `docs/运维手册.md` 第 2 节。

## 一、数据库

```bash
sudo -u postgres createdb fly
sudo -u postgres psql -d fly -f fly-backend/init_db.sql
# 创建管理员账号 feifei（密码取 ADMIN_INITIAL_PASSWORD，脚本无默认值，必须先设置）
sudo -u postgres env POSTGRES_USER=postgres POSTGRES_DB=fly \
  ADMIN_INITIAL_PASSWORD='你的管理员密码' bash fly-backend/init_admin.sh
```

`init_db.sql` 包含 19 张表与站点配置种子数据（不含任何账号），仅需执行一次；
`feifei` 管理员账号由 `init_admin.sh` 单独创建，跳过该步骤将无法登录管理后台。

## 二、后端（Spring Boot）

```bash
cd fly-backend

# 1. 配置环境变量
cp .env.example .env
# 编辑 .env：填写 FLY_SECRET_KEY（必填，至少 32 字符）及数据库连接

# 2.（可选）构建后端自带的 Vue 后台产物
#    线上 /admin 走 Next.js 前端页面，此步骤仅在需要直连后端 :8000 打开 Vue 后台时执行
cd admin
pnpm install && pnpm build        # 产出 admin/dist
cd ..

# 3. 打包
mvn -DskipTests package           # 产出 target/fly-backend.jar

# 4. 启动（在 fly-backend 目录下运行，uploads/、admin/dist 按相对路径查找）
set -a; source .env; set +a
java -jar target/fly-backend.jar
```

验证：`curl http://127.0.0.1:8000/api/health` → `{"status":"ok"}`

### systemd 示例（`/etc/systemd/system/fly.service`）

```ini
[Unit]
Description=Fly Backend
After=network.target postgresql-16.service

[Service]
WorkingDirectory=/opt/fly/fly-backend
EnvironmentFile=/opt/fly/fly-backend/.env
ExecStart=/usr/bin/java -jar target/fly-backend.jar
Restart=on-failure
User=fly

[Install]
WantedBy=multi-user.target
```

```bash
# 创建专用服务用户并授权（Rocky 无 www-data 用户；uploads/ 需可写）
sudo useradd -r -s /sbin/nologin fly
sudo chown -R fly:fly /opt/fly/fly-backend
sudo systemctl daemon-reload && sudo systemctl enable --now fly
```

> SELinux enforcing 主机上若服务起不来，检查 `ausearch -m avc -ts recent`；
> jar 与 uploads 已在同一用户下，通常无需额外打标。

## 三、前端（Next.js）

```bash
cd Fly
pnpm install

# SSR 首页数据抓取的后端地址（生产建议指向后端实际地址）
export NEXT_PUBLIC_API_URL=http://127.0.0.1:8000

pnpm build
pnpm start                        # 默认监听 3000
```

systemd / PM2 守护方式与后端类似，`ExecStart` 换成
`pnpm start`（WorkingDirectory 指向 `fly/`）即可。

## 四、Nginx

在 `deploy/nginx.conf` 基础上把 upstream 的服务名改为本机地址即可。**注意：务必保留
`deploy/nginx.conf` 中 `http {}` 段的限流/防爆破/安全头配置**（`limit_req_zone`/`limit_conn_zone`
定义、`location = /api/auth/login` 的 1 r/s 限流、`add_header X-Content-Type-Options nosniff`
等），照抄下方最小示例会丢失这些防护；生产环境建议直接改 `deploy/nginx.conf` 而不是用示例：

```nginx
# ---- 以下限流 zone 须放在 http {} 段（与 deploy/nginx.conf 保持一致）----
limit_conn_zone $binary_remote_addr zone=addr_conn:10m;
limit_req_zone  $binary_remote_addr zone=api_rate:10m rate=30r/s;
limit_req_zone  $binary_remote_addr zone=music_rate:10m rate=2r/s;
limit_req_zone  $binary_remote_addr zone=uapis_rate:10m rate=5r/s;
limit_req_zone  $binary_remote_addr zone=login_rate:10m rate=1r/s;
limit_req_zone  $binary_remote_addr zone=reader_rate:10m rate=10r/s;

upstream frontend_server { server 127.0.0.1:3000; }
upstream backend_server  { server 127.0.0.1:8000; }

server {
    listen 80;
    server_name your-domain.com;
    client_max_body_size 100m;

    limit_conn addr_conn 40;
    limit_req_status 429;
    limit_conn_status 429;
    add_header X-Content-Type-Options nosniff always;

    proxy_http_version 1.1;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    # 覆写而非追加：nginx 是唯一可信边界，丢弃客户端伪造的 X-Forwarded-For
    proxy_set_header X-Forwarded-For $remote_addr;
    proxy_set_header X-Forwarded-Proto $scheme;

    # 登录接口防爆破（必须先于 /api/ 精确匹配）
    location = /api/auth/login {
        limit_req zone=login_rate burst=5 nodelay;
        proxy_pass http://backend_server;
    }
    # 音乐歌单（Next.js Meting 路由，必须在 /api/ 之前精确匹配）
    location = /api/music {
        limit_req zone=music_rate burst=10 nodelay;
        proxy_pass http://frontend_server;
    }
    # 前端自有 API 路由（Next route handler，必须先于 /api/ 匹配，否则被截给后端 404）
    location /api/uapis {
        limit_req zone=uapis_rate burst=10 nodelay;
        proxy_pass http://frontend_server;
    }
    location /api/     { limit_req zone=api_rate burst=40 nodelay; proxy_pass http://backend_server; }
    location /uploads/ { proxy_pass http://backend_server; }
    location = /admin  { proxy_pass http://frontend_server; }
    location /admin/   { proxy_pass http://frontend_server; }

    # 小说阅读服务（内置 reader3 协议；SSE 必须关闭缓冲）
    location /reader3/ {
        limit_req zone=reader_rate burst=30 nodelay;
        proxy_pass http://backend_server;
        proxy_connect_timeout 30s;
        proxy_read_timeout 120s;
        proxy_buffering off;
        proxy_cache off;
        proxy_set_header Connection "";
    }

    location / {
        proxy_pass http://frontend_server;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        # 必须禁用代理缓存，否则重新部署后会返回旧 HTML
        proxy_cache off;
        add_header Cache-Control "no-cache, no-store, must-revalidate" always;
    }
}
```

## 五、访问入口

- 博客前台：`http://your-domain.com/`
- 管理后台：`http://your-domain.com/admin`（Next.js 页面，用户名 `feifei`，密码为执行
  `init_admin.sh` 时传入的 `ADMIN_INITIAL_PASSWORD` 值（脚本无默认值，未设置会直接报错），登录后请立即修改）

## 常见问题

- **启动即退出**：`FLY_SECRET_KEY` 缺失或少于 32 字符，后端会直接失败。
- **页面更新后浏览器仍显示旧版**：确认 Nginx 对 `/` 关闭了代理缓存（见上）。
- **图片无法上传**：未配置 `FLY_OSS_*` 时图片保存到本地 `uploads/` 目录（经
  `/uploads/` 访问）；若本地也失败，检查 `uploads/` 目录权限。
- **管理后台 404**：`/admin` 由前端 Next.js 提供，确认 frontend 已构建并运行在 3000
  （`pnpm build && pnpm start`），且 Nginx 的 `/admin` 两条 location 指向 `frontend_server`。
